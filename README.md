# Restaurante Cabeça de Bagre — Cozinha do Mar

Site institucional estático, em português, para o restaurante em Vila Isabel, Rio de Janeiro. A página inicial é `index.html`; `index-cabeca-bagre.html` é mantido como alternativa com o mesmo conteúdo.

## Publicação

O GitHub Actions publica o site no GitHub Pages sempre que há um commit na branch `main`. O workflow envia somente os HTMLs, arquivos de descoberta e os assets utilizados pela página.

O domínio configurado é `cabecadebagre.com.br`. Para acessá-lo, o DNS do domínio precisa apontar para o GitHub Pages. Antes de configurar o DNS, o endereço padrão do projeto fica disponível em `https://darioari.github.io/cabecadebagre/`.
